Universe OS // Capability Gate

This observatory opens on desktop-class hardware.

Universe OS is intentionally built around a high-capability, desktop-first WebGPU runtime. If the device cannot support the observatory baseline, the product should say so clearly instead of pretending a reduced shell is the full experience.
