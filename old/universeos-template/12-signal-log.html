Universe OS // Signal Log

Status should read like observatory events, not toast spam.

This page collects the transient language of the system: route changes, survey commits, cruise pauses, submission receipts, and local capability warnings. The UI stays lightweight, but every message still feels like it belongs inside a living observatory.

Behavior

Short lived by default

The log should surface events and then get out of the way, unless the user opens the full history drawer.

Tone

Precise, not dramatic

A receipt can still feel poetic, but it should never make the user guess whether the action truly succeeded.

Placement

Near the current action

Receipts should stay attached to the route or panel that caused them, not appear as anonymous global popups.
