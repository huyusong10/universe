# Distant sky imagery

The six cube faces are copied, without image edits, from the user-supplied reference project `/Users/hys/dev/100k-Star-Challenge/index_files/s_*.jpg`.

That project's README identifies its source as the Google Chrome Experiment [100,000 Stars](https://stars.chromeexperiments.com/). This is source attribution, not a new license grant.

These images provide distant, non-selectable visual context. The generated catalog remains the source of selectable star identities. Exposure, color treatment, lens angle and transition are applied by the GPU renderer.
